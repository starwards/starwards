# MS3 — Milestone 3 design corpus (Historical)

Design, planning, and pre-engineering documents produced for Milestone 3 (Nov 2025).

**Read these as history, not as current plans.** The strategic framing has since narrowed to a
4-station bridge — see [decision 004](../design/decisions/004-ship-early-expand-later.md) — and
current planning lives in the [starwards-design](https://github.com/starwards/starwards-design)
`product/` KB. Several documents here still carry their original "Open" / "In Progress" status
headers from that period; those statuses are frozen in time.

The engineering detail remains useful: the scan-levels, signals-jobs, and warp-topology designs
are still the fullest write-ups of those mechanics, and are linked from the live station docs.
