# Vision

Starwards is a multiplayer spaceship bridge simulator where crews of 2-6 players operate
stations on a starship — piloting, weapons, engineering, signals intelligence, navigation, and
communications. It is built for Live Action Role-Playing events in the
[Helios universe](https://helios-larp.web.app), a hard sci-fi 23rd-century Sol system setting.

**The full vision — audiences, principles, and why not EmptyEpsilon — lives in the design KB:
[starwards-design `product/vision.md`](https://github.com/starwards/starwards-design/blob/main/product/vision.md).**
That copy is canonical; change it there. This page exists so the code repo has an orientation
entry point.

The five design principles that most shape the code:

1. **Systems create roles** — same ship, different readouts per station, different expertise.
2. **Interaction is negative** (Bret Victor) — screens display; physical controls act; minimize clicks.
3. **Malfunction over destruction** — damage breaks systems; no hit points; no ship explosions.
4. **The GM is the storyteller** — rules never auto-kill player ships.
5. **Foundation-first** — build systems others derive from.

Physics-based and internally coherent: no energy shields, no artificial drag.
