# Starwards Design Hub

Starwards is a multiplayer spaceship bridge simulator built for LARP events. Players crew stations on a simulated starship — piloting, firing weapons, managing engineering systems, scanning contacts, and coordinating as a team. It replaces the legacy [EmptyEpsilon](https://github.com/starwards/EmptyEpsilon) system with a ground-up rebuild optimized for lengthy, narrative-driven LARP play.

This repository is the **product and project management hub**. Technical documentation lives in the [starwards repo](https://github.com/starwards/starwards). This is where we track *what* to build and *why*.
