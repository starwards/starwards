allow sets of waypoints in each ship. 

a waypoint is a combination of name and space position. each set has a name and color, and can have any number of waypoints. each waypoint by default gets named by the computer (use a counter).

each ship has a special set of waypoints called "course" that is editable by the relay station, and also displayed in helm radars (warp or thrusters mode).

in addition a number of sets that are editable in the navigator radar and viewable (cherry-picked) at the relay station.
